2. `version_detect.py`, `version_map.py`는 가져가되, 버전 변환은 2 · 3번 영역과 겹치므로 PR 설명에 "화면 쪽 임시 구현, 팀 변환 로직이 생기면 교체"라고 적는다
3. OpenAI 키는 followups 를 빼므로 화면 쪽에는 필요 없음

## 선택 기능 빼는 법

선택 기능은 모두 `src/ui/extras/` 한 폴더에 있고, 화면은 `src/ui/optional.py`의 `load()`로만 부릅니다.

| 빼는 방법 | 결과 |
|---|---|
| `src/ui/extras/` 폴더 통째로 빼기 | 화면은 그대로 동작. 연상 질문 · 코드 없는 질문 답변 · 버전 감지 안내 · 1.x 가 아닌 방향 변환만 빠짐 |
| 파일 하나만 빼기 (예: `followups.py`) | 그 기능만 빠짐 |

`app.py`에서 선택 기능을 쓰는 곳은 `# [선택 기능: …]` 주석으로 표시해 두었습니다. 폴더를 빼면 그 부분은 자동으로 건너뛰므로 **코드를 지우지 않아도 됩니다**. 깔끔하게 지우고 싶으면 그 주석 사이만 지우면 됩니다.

2026-10-14 확인: `extras/` 폴더를 지운 사본에서 1.x 변환, 예시 질문, 코드 없는 질문, 되돌리기 안내가 **오류 없이** 동작.

## 팀 저장소와 겹치는 파일 (2026-10-14 확인)

| 파일 | 상황 | 처리 |
|---|---|---|
| `app.py` | 1번이 dev 에서 그래프 실행 시험용으로 사용 중 | 덮어쓰기로 결정됨. 머지 전에 1번과 이야기하고, 1번의 시험 코드가 필요하면 다른 파일로 옮겨 달라고 부탁 |
| 그 밖의 내 파일 | `src/ui/`, `eval/`, `tools/`, `docs/`, `.streamlit/`, `requirements.txt` 는 팀 저장소에 없음 | 충돌 없음 |

`requirements.txt`는 팀이 `pyproject.toml`(uv)을 쓰므로, 머지할 때는 패키지를 `uv add`로 옮기는 것이 맞습니다 (1번과 상의).

## 배포 서버 (지금)

| 항목 | 지금 | 나중에 |
|---|---|---|
| TiDB 접속 정보 | 없음 → SQLite (재시작하면 기록 사라짐) | Streamlit Cloud 앱 설정 → Secrets 에 `[tidb]` 넣으면 코드 수정 없이 TiDB 사용 |
| OpenAI 키 | 없음 → 연상 질문 · 코드 없는 질문 답변 안 나옴 | Secrets 에 `OPENAI_API_KEY` (followups 를 가져갈 때만 필요) |
| 2번 데이터 | 없음 → 근거 예시, 1.x 가 아닌 방향 변환 안 됨 | 팀 저장소로 합치면 자동으로 실제 데이터 사용 |

즉 지금 배포는 **화면 동작 확인용**이고, 실제 데이터 · DB · 키는 팀 저장소에 합친 뒤 또는 Secrets 를 넣은 뒤에 붙습니다.
