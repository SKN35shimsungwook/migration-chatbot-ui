# 화면 실행 방법 (4번 · 화면)

> LangChain 버전 마이그레이션 코드 어시스턴트 챗봇 화면(`app.py`)을 켜는 방법입니다.
> Windows PowerShell은 `&&`로 명령을 이어 붙일 수 없으니 **한 줄씩** 실행합니다.

**설치 없이 바로 보기 (배포)**: [https://migration-chatbot-ui-47wunvzaww7qc27nmwufvh.streamlit.app/](https://migration-chatbot-ui-47wunvzaww7qc27nmwufvh.streamlit.app/)  
배포 화면은 2번 데이터가 없는 버전이라 근거 ID와 자동 감지가 예시로 동작합니다. 실제 데이터로 보려면 아래처럼 팀 저장소에서 켭니다.

## 1. 처음 한 번

```powershell
uv sync
```

```powershell
uv pip install -r requirements.txt
```

| 패키지 | 쓰는 곳 |
|---|---|
| `streamlit` | 화면 전체 |
| `sqlalchemy`, `pymysql`, `certifi` | 대화 기록 저장 (TiDB) |
| `openai` | 연상 질문, 코드 없는 질문 답변 |

## 2. 비밀 값 넣기 (선택)

`.streamlit/secrets.toml.example`을 복사해서 `.streamlit/secrets.toml`로 저장하고 값을 채웁니다. 이 파일은 Git에 올리지 않습니다.

| 값 | 없으면 |
|---|---|
| `OPENAI_API_KEY` | 연상 질문이 안 나오고, 코드 없는 질문에는 "키를 설정하면 답할 수 있다"고 안내 |
| `[tidb]` host · port · user · password · database | 내 컴퓨터의 `data/local_chat.db`(SQLite)에 저장 |

TiDB는 `database`에 적은 데이터베이스를 미리 만들어 두면, 테이블(`users`, `conversations`, `messages`)은 화면이 처음 켜질 때 자동으로 만듭니다.
Streamlit Cloud에서는 앱 설정 → **Secrets**에 같은 내용을 붙여 넣습니다.

## 3. 화면 켜기

```powershell
uv run streamlit run app.py
```

브라우저가 자동으로 열립니다. 끌 때는 터미널에서 `Ctrl + C`.

## 4. 화면 구성

| 위치 | 내용 |
|---|---|
| 로그인 | **처음이에요**: 새 username 만들기 (한글 · 영문 · 숫자 · _ 2~20자, **중복 금지**) / **이어서 하기**: 내 username으로 들어가기 |
| 사이드바 | ChatGPT처럼 **새 대화**, **내 대화 목록**(누르면 그 대화와 결과를 다시 불러옴), 로그아웃 |
| 위쪽 | **옛 버전**(모르면 자동 감지) · **변환할 버전**(LangChain 1.x, 현재 최신 1.4.4) |
| 왼쪽 채팅 | 옛 코드나 질문 입력, 처음에는 **예시 질문 4개**, 답변 아래 **이어서 물어보기**(연상 질문) |
| 오른쪽 결과 | 검증 배지 · 버전 · 근거 출처, 탭: 전후 비교 / 변경표 · 근거 / 진행 과정 |

## 5. 저장되는 것 (TiDB)

| 테이블 | 열 |
|---|---|
| `users` | `user_id`(키) · `username`(중복 금지) · `created_at` |
| `conversations` | `conv_id` · `user_id` · `title`(첫 메시지) · `source_version` · `target_version` · 시각 |
| `messages` | `msg_id` · `conv_id` · `role`(user / assistant) · `content` · `result_json`(결과 패널) · `created_at` |

내 대화 목록에는 **내 user_id의 대화만** 나옵니다.

## 6. 지금 화면이 쓰는 것

| 부분 | 지금 |
|---|---|
| 버전 · 근거 ID(`imap-…`) · 자동 감지 | 2번 데이터 (`data/processed/import_map.jsonl`, `src/rag/retrieval/`) |
| 코드 변환 결과 | 가짜 결과 (`src/ui/mock.py`). 챗봇이 연결되면 `src/ui/client.py`의 `run()`이 진짜 결과를 돌려줌 |
| 예시 질문 | `eval/questions.json` (실무형 질문 30개) |

## 7. 자동 점검

```powershell
uv run python tools/bot_check.py
```

가입 · 중복 금지 · 로그인, 버전 선택 13가지, 예시 질문, 대화 저장 · 다시 열기, 사용자 분리까지 22가지를 임시 SQLite로 점검합니다 (TiDB에는 쓰지 않음). 마지막 줄에 `22/22 통과`가 나오면 정상입니다.

## 8. 자주 나는 문제

| 증상 | 해결 |
|---|---|
| `ModuleNotFoundError` (streamlit, sqlalchemy, pymysql, openai) | 1장의 `uv pip install -r requirements.txt` |
| `'&&' 토큰은 이 버전에서 올바른 문 구분 기호가 아닙니다` | 명령을 한 줄씩 실행 |
| 사이드바 아래 "기록: SQLite(로컬)" | `secrets.toml`에 `[tidb]`가 없음. 2장 확인 |
| TiDB 연결 오류 (SSL, Access denied) | host · user(`<prefix>.root` 형식) · password, 데이터베이스를 먼저 만들었는지 확인 |
| 이어서 물어보기가 안 나옴 | `OPENAI_API_KEY` 없음. 2장 확인 |
| 근거 ID가 `sample-…`로 나옴 | 2번 데이터가 없는 폴더에서 실행한 것. 팀 저장소 최신 상태에서 실행 |
